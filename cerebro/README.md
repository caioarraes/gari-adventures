# Segundo cérebro

Memória do desenvolvimento. Cada informação tem um lugar só. Os outros arquivos apontam para ela.

| Arquivo | Guarda | Atualize quando |
|---|---|---|
| [diario.md](diario.md) | Estado atual e próximo passo | Toda sessão com mudança real |
| [visao.md](visao.md) | Experiência desejada | O usuário mudar a ideia do jogo |
| [mecanicas.md](mecanicas.md) | Mecânicas definidas e hipóteses | Uma mecânica for definida ou mudar |
| [roadmap.md](roadmap.md) | Fases e sistemas complexos mapeados | O plano mudar, com aprovação do usuário |
| [decisoes.md](decisoes.md) | Decisões tomadas e motivos | Uma decisão for tomada |
| [duvidas.md](duvidas.md) | Perguntas em aberto | Surgir ou se resolver uma dúvida |
| [precedentes.md](precedentes.md) | Jogos de referência e fontes | Uma pesquisa trouxer algo útil |
| [reciclagem.md](reciclagem.md) | Reaproveitamento real de cada inimigo | Um inimigo for criado ou mudar |
| [tecnico-godot.md](tecnico-godot.md) | Instalação e fatos técnicos testados | Algo técnico for confirmado |
| [entrega.md](entrega.md) | Prazo, documentos da entrega e pendências do grupo | Mudar o jogo, um documento ou uma pendência |

## Convenções

- **Definido** veio do usuário ou foi aprovado por ele.
- **Hipótese** é proposta ainda não aprovada. Não trate como requisito.
- **Testado** foi executado na Godot instalada. Sem essa marca, é informação de fonte externa.
- Ao resolver uma dúvida, mova o resultado para `decisoes.md` e apague a dúvida.

As regras de trabalho estão em [../AGENTS.md](../AGENTS.md). Os agentes estão em [../.claude/agents/](../.claude/agents/).
